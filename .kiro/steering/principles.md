# Steering Principles for Dhoya-Mukto Poth

## This is Not a Commercial Website.

This is a mission to save lives from tobacco addiction, presented as a product.

Every decision — design, copy, code — must reflect this truth.

## The Visitor is Family.

Treat every visitor as if they were your own brother, sister, or parent.

Would you pressure your mother with fake countdowns? Then don't do it here.

## Dignity Over Conversion.

If a design pattern would convert 2x more but feel manipulative — reject it.

Long-term trust outweighs short-term sales.

## Silence is Sacred.

Use whitespace generously. Let ideas breathe.

Cluttered pages feel desperate. We are not desperate.

## The Founder's Story is Sacred.

Never add a buy button inside the founder's story section.

Let the emotion settle. Let people feel, not buy.

## Islamic Content is Holy.

Arabic verses must be rendered correctly with proper font.

Never use Islamic content as a "marketing angle" — treat it with reverence.

## Accessibility is Not Optional.

A blind grandmother should be able to navigate this with a screen reader.

A villager with a 2015 phone should be able to load this page.

## The 41-Day Promise is Binding.

If a refund is requested, honor it immediately, without argument.

If the 3 points are valid, send the gift without hesitation.

Our word is our bond.

## Performance is Respect.

Every unnecessary kilobyte is an insult to users on slow connections.

Optimize images. Lazy-load. Cache aggressively.

## When in Doubt — Ask.

If unsure about a choice, note it in a `NEEDS_REVIEW.md` file.

Don't guess on ethical or emotional content.
